    Phone alarms

    A Shortcut on your iPhone reads today’s tasks and sets a Clock alarm at the start and end of each one. Set it up once (about 3 minutes), then it runs by itself every morning.

    Your alarms today
    • Loading…

    1 · Build the Shortcut

    1. Open the Shortcuts app → + → name it CoWork alarms.
    2. Add Get Contents of URL. Paste this URL:
    3. Tap Show More. Set Method to POST.
    4. Under Headers add two:
      Keyapikey
      Value
      KeyContent-Type
      Valueapplication/json
    5. Set Request Body to JSON and add two Text fields:
      p_pinopen
      p_who
    6. Add Repeat with Each (it uses Contents of URL).
    7. Inside the repeat, add Get Dictionary Value → Value for time in Repeat Item.
    8. Add another Get Dictionary Value → Value for label in Repeat Item.
    9. Add Create Alarm (Clock): time = the first Dictionary Value, label = the second. Turn off “Show When Run”.
    10. Tap ▶︎ to test. Your alarms appear in the Clock app.

    2 · Run it every morning

    1. Shortcuts → Automation → + → Time of Day, e.g. 7:00, Daily.
    2. Choose Run Immediately, then pick CoWork alarms.

    Alarms are for the day the Shortcut runs. Tasks you’ve declined (meetings) are skipped. Clock keeps old one-off alarms in its list switched off; swipe to delete them now and then.
